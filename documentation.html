📄 Project Documentation

CineHub – Web Programming 2 | Mina Jevtic, 75/23

1. Project Overview

CineHub is an interactive website featuring a catalog of movies and TV series. Users can search, sort, and filter content, save titles to a favorites list, and send contact messages. All pages are fully responsive and optimized for search engines.

Topic

Movies and series — an interactive catalog with sorting by rating, year, and title, filtering by genre and minimum rating, and "Load More" pagination.

5. Features

5.1 AJAX and JSON

Data is loaded asynchronously via $.ajax() from JSON files (data/movies.json and data/series.json). Each entry has a nested rating object (with imdb, userAvg, votes), a cast array (with name and role), and a tags array. The home page uses $.when() to load both files in parallel.

5.2 Sorting

The sortItems(field, order) function sorts the filtered array by a chosen field and order. Supported fields: rating, year, title, duration. Order: ascending (asc) or descending (desc).

5.3 Filtering

The filterItems() function applies multiple filters at once:

  • Genre (checkbox list — multiple genres can be selected)
  • Minimum IMDb rating (range input)
  • Text search by title, director, and tags (debounced, 350ms)

5.4 Pagination ("Load More")

Shows ITEMS_PER_PAGE (6) items per page. The "Load More" button loads the next group. The total and currently shown count are always visible.

5.5 Favorites (My List)

Users can add or remove any movie or series from their list by clicking the ♡ button on a card. IDs are saved in localStorage under cineHub_favMovies and cineHub_favSeries. The favorites page loads and displays saved items and shows a badge count in the navbar.

5.6 Contact Form and Validation

The form has 7 input types: text, tel, email, select, textarea, radio, and checkbox. Validation is done with regular expressions in form.js. Error messages appear below each field. Successfully submitted forms are saved in localStorage.

5.7 Error Handling

try/catch is used in all critical places: AJAX callbacks, JSON parsing, localStorage operations, and filter/form validation. Users see toast notifications and inline error messages.

5.8 localStorage

All localStorage operations go through lsSave() and lsLoad() helpers. Stored keys: cineHub_favMovies, cineHub_favSeries, cineHub_lastSearch, cineHub_messages.

7. Responsive Design and SEO

The site uses CSS Grid and Flexbox for responsive layout. Breakpoints are set at 900px, 700px, and 480px. A hamburger menu appears on mobile. All images have loading="lazy". Every page has title, description, keywords, author, and robots meta tags. The home page also has Open Graph tags. Semantic HTML5 elements (<nav>, <main>, <footer>, <section>) and ARIA attributes are used throughout.

8. Running the Project

Because of AJAX calls for loading JSON files, the site must be served through a local web server (not opened directly from the file system). Recommended options:

  • VS Code extension Live Server — right-click index.html → "Open with Live Server"
  • python -m http.server 8000 — run in the project root folder
  • XAMPP / WAMP / MAMP — copy the project into the htdocs folder
